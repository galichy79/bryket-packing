# История диалогов — bryket-packing

Калькулятор фасовки и погрузки топливных брикетов: мешок → поддон → машина.
Одностраничный `index.html` на украинском языке, без сборки и зависимостей.

---

### 2026-09-30 — Создание калькулятора

**Запрос пользователя**
«Создай проект фасовка и погрузка брикета. Назови каталог тематически.»

**Уточнения и решения**

Из ответов на вопросы:
- тип проекта — **калькулятор** (не сайт, не бизнес-план, не видео);
- каталог — `/home/u/bryket-packing`;
- формат — **один HTML-файл** (открывается двойным щелчком, сборки нет);
- язык интерфейса — **украинский**.

**Что сделано**

Создан `index.html` — самодостаточный калькулятор: разметка, CSS и вся логика
расчёта в одном файле, ванильный JS, без внешних зависимостей.

Структура расчёта:
- плотность брикета по типу (Pini-Kay 1250, Nestro 1100, Ruf 1000, ручной ввод);
- фасовка: вес мешка, мешков на поддоне, тип поддона, коэффициент заполнения
  объёма, цена мешка / поддона / стрейча;
- транспорт: 6 пресетов машин (тент 20 т и 22 т, контейнеры 20' и 40',
  манипулятор, газель) с грузоподъёмностью, объёмом и высотой кузова, плюс
  ручное переопределение числа паллет;
- погрузка: 4 пресета способов с производительностью и тарифом;
- партия: количество машин.

Выводы: карточки «Одна машина», «Партія», «Час робіт» (последовательно и
параллельно) и «Вартість» (постатейно, итог, себестоимость 1 т и 1 мешка).
Плюс флаги-предупреждения о превышении высоты кузова и о перегрузе.

Дополнительно: сохранение параметров в localStorage, кнопка сброса,
печать/PDF с отдельными print-стилями (форма ввода при печати скрывается).

**Проверка**

Калькулятор открыт в браузере через Playwright, расчёт сверен с ручным
пересчётом — совпал на всех трёх прогонах (дефолт, погрузчик, контейнер 20').
Проверены: переключение пресетов, сохранение в localStorage после перезагрузки,
срабатывание предупреждения «Не влізе по висоті» (пакет 2,92 м при кузове
2,39 м), переключение полей в ручной режим.

**Найденные и исправленные проблемы**

1. Подписи единиц измерения налезали на числа в полях: единицы стояли
   абсолютным позиционированием с фиксированным `padding-right`, которого не
   хватало для длинных подписей вида «грн/піддон» и «мішків/год». Переделано
   на flex-раскладку (`input` растягивается, подпись занимает своё место).
   Проверено скриптом: 15 полей, пересечений 0.

**Файлы**

- `index.html` — калькулятор (создан)
- `README.md` — описание, логика, параметры по умолчанию, ограничения (создан)
- `История_диалогов.md` — этот файл

**Известные ограничения**

Расчёт по одной позиции, без накопительного списка партий. Раскладка паллет
по площади пола кузова не моделируется — для еврофуры это 33 паллеты по факту
против 32 в расчёте по массе.
