# Калькулятор расценок на фасовку и складирование брикета

**Работает здесь: https://bryket.netlify.app/**

Одностраничный калькулятор на украинском языке: считает **стоимость работ**
по фасовке брикета в мешки и складированию этих мешков на поддоны.

Стоимость брикета, мешков, поддонов, стретч-плёнки и транспорта не
считается — только труд.

## Как запустить

Проект собирается Vite 8, стили — Tailwind CSS 4.

```bash
npm install      # один раз
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр собранного
```

`npm run build` собирает **один самодостаточный `dist/index.html`** (плагин
single-file): его можно открыть двойным щелчком прямо с диска, без сервера и
без интернета. Это самый простой способ передать калькулятор кому-то ещё.

## Деплой на Netlify

**https://bryket.netlify.app/**

`netlify.toml`: команда сборки `npm run build`, публикация `dist`, Node 22.
Каждый push в `main` пересобирает сайт автоматически.

## Состав работ

| № | Операция | Что входит |
|---|---|---|
| 1 | Фасовка мешка | набрать брикеты из кучи в мешок, завязать |
| 2 | Переноска на 10 м | перенести мешок, только туда — обратный ход не входит |
| 3 | Укладка на место складирования | уложить мешок на поддон, высота до 1,5 м |

Всё вручную, мешками. Погрузчик, манипулятор и конвейер не предусмотрены.

## Что на входе

Масса брикета в куче (по умолчанию 6 т), вес мешка (30 кг по умолчанию),
нормы времени на каждую операцию (в секундах), количество работников (1)
и тариф за час. Количество мешков считается автоматически: масса партии /
вес мешка. Если вес мешка превышает 35 кг, выводится предупреждение
о безопасности.

## Срок выполнения

Трудоёмкость считается в человеко-часах и от числа людей не зависит.
Срок = человеко-часы / количество работников, при условии параллельной
работы без потерь на согласование.

```
20,6 люд.-год ÷ 3 ос. = 6,9 год
```

Стоимость работ от числа работников не меняется — те же человеко-часы
по тому же тарифу. Меняется только срок.

## Что на выходе

| Блок | Что показывает |
|---|---|
| Норми часу | таблица: операция, время на мешок (поле ввода), количество мешков, общее время; строка «Разом» |
| Розцінки за один мешок | таблица по трём операциям: время, грн/мешок, грн за партию; итоговая строка складывается из строк |
| Підсумок по партії | стоимость работ, срок выполнения, цена тонны, цена мешка |
| Предупреждения | тариф ниже 300 грн/час; мешок тяжелее 35 кг |

## Формула

```
расценка = время_операции / 3600 × тариф
```

## Нормы времени по умолчанию

| Операция | Норма | Выработка |
|---|---|---|
| Фасовка (набрать из кучи + завязать) | 300 с (5 мин) | 12 мешков/час |
| Переноска на 10 м, только туда | 60 с (1 мин) | 60 мешков/час |
| Укладка на поддон до 1,5 м | 10 с | 360 мешков/час |
| Полный цикл | 370 с (6 мин 10 с) | 9,7 мешка/час |

Это фактические нормы производства, а не оценка. Вводятся в секундах, в
таблице сразу видно, сколько мешков и сколько часов даёт каждая операция.

## Тариф по умолчанию

**450 грн/час** — стандартная ставка киевского сервиса грузчиков в 2026 году.

| Кто выполняет | грн/час |
|---|---|
| Штатный рабочий (себестоимость) | 200 |
| Подрядная бригада / ФОП | 350 |
| Сервисная компания (стандарт) | 450 |
| Премиум / срочно | 500+ |

Обоснование ставок и норм, со ссылками на источники — в `ТЗ_калькулятор.md`
(раздел 12) и `История_диалогов.md`.

## Контрольный расчёт

6 т, мешки 30 кг → 200 мешков, нормы 300/60/10 с, тариф 450 грн/час:

| Операция | Грн/мешок | Грн за партию |
|---|---|---|
| Фасовка | 37,50 | 7 500 |
| Переноска | 7,50 | 1 500 |
| Укладка | 1,25 | 250 |
| **Разом** | **46,25** | **9 250** |

За тонну — 1 542 грн. Время — 20,6 часа.

## Возможности

- Параметры сохраняются в localStorage, кнопка «Скинути» возвращает значения
  по умолчанию.
- Кнопка «Друк / PDF» — печать расчёта: форма ввода скрывается, остаются
  только результаты.


## Мобильные

Вёрстка одна колонка до 1024 px, дальше две. Числа в таблицах не переносятся,
на экранах уже 640 px колонка «Мішків» и длинные заголовки сокращаются,
страница не выезжает по горизонтали начиная с 320 px. Шрифты только
системные — веб-шрифты не загружаются.

## Ограничения

- Расчёт по одной позиции за раз, без накопительного списка партий.
- Количество поддонов и раскладка мешков по поддонам не считаются.
- Нормы времени — фактические для одного производства, а не средние
  по отрасли. Для другого процесса их нужно подставить свои.
