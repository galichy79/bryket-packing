# Калькулятор фасовки и погрузки брикета

Одностраничный калькулятор на украинском языке: считает, сколько топливных
брикетов влезает в мешок, на поддон и в машину, сколько это занимает времени
и сколько стоит.

## Как запустить

Открыть `index.html` двойным щелчком в браузере. Сборка не нужна, зависимостей
нет — весь калькулятор в одном файле.

## Что считает

| Блок | Что показывает |
|---|---|
| Одна машина | мішків на піддоні (шт × кг), вага нетто/брутто, об'єм вантажу, висота пакета, піддонів у машину, мішків і тонн у машині, заповнений об'єм кузова |
| Партія | піддонів, мішків і тонн на задану кількість машин |
| Час робіт | час фасування, час навантаження, разом послідовно і паралельно |
| Вартість | брикет, мішки, піддони, стрейч, робота; разом і собівартість 1 т / 1 мішка |

## Ключевая логика

- **Объём груза на поддоне** = масса нетто / плотность / коэффициент заполнения.
  Коэффициент (0,7–0,8 для мешков) учитывает пустоты между мешками.
- **Паллет в машину** = минимум из ограничения по массе и по объёму.
  В расчёте видно, какой лимит сработал: брикет — тяжёлый груз, поэтому обычно
  упирается в грузоподъёмность.
- **Висота пакета** = объём груза / площадь поддона + высота поддона (0,144 м).
  Если выше кузова — выводится красное предупреждение.
- **Перегруз** — отдельное предупреждение, если паллеты тяжелее
  грузоподъёмности машины (например, при ручном переопределении).

## Параметры по умолчанию

Плотность: Pini-Kay 1250 кг/м³, Nestro 1100, Ruf 1000. Поддоны: EUR 1200×800
(0,96 м²), финский 1200×1000, половинный 800×600. Машины: тент 20 т / 82 м³,
тент 22 т / 92 м³, контейнеры 20' и 40', манипулятор, газель. Нормы погрузки:
вручную 120 мешков/ч (180 грн/ч), погрузчик 25 паллет/ч (500 грн/ч),
манипулятор 15 паллет/ч (700 грн/ч), конвейер 40 паллет/ч (250 грн/ч).

**Значения ориентировочные.** Плотность и цену брикета брать у поставщика,
норму фасовки — по факту смены. Цены в гривне, актуальны на 2026 г.

## Возможности

- Все типы, поддоны, машины и способы погрузки переключаются на «Інший» —
  поля становятся редактируемыми для ручного ввода.
- Параметры сохраняются в localStorage браузера, кнопка «Скинути» возвращает
  значения по умолчанию.
- Кнопка «Друк / PDF» — печать текущего расчёта (интерфейс ввода при печати
  скрывается, остаются только результаты).

## Ограничения

- Расчёт по одной позиции за раз, без накопительного списка партий.
- Паллеты считаются штабелируемыми слоями по объёму; раскладка на полу кузова
  (сколько паллет реально встанет по площади) не моделируется — для
  еврофуры это 33 паллеты против 32 по массе в дефолтном расчёте.
- Стоимость рабочей силы считается по часам фасовки + погрузки, без
  разделения бригад.
