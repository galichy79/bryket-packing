# Калькулятор фасовки и погрузки брикета

Одностраничный калькулятор на украинском языке: считает, сколько мешков
брикета влезает на поддон и в машину, сколько это занимает времени и сколько
**стоят работы** по фасовке и погрузке.

Стоимость самого брикета, мешков, поддонов и стретч-плёнки не считается —
только труд.

## Как запустить

Открыть `index.html` двойным щелчком в браузере. Сборка не нужна,
зависимостей нет — весь калькулятор в одном файле.

## Состав работ

| Операция | Что входит |
|---|---|
| Фасовка | набрать брикеты в мешок, завязать |
| Погрузка | перенести мешок до 10 м, уложить на поддон, погрузить в машину |

Погрузка только ручная, мешками. Погрузчик, манипулятор и конвейер не
предусмотрены.

## Что показывает

| Блок | Что показывает |
|---|---|
| Одна машина | мешков на поддоне (шт × кг), вес нетто/брутто, объём груза, высота пакета, поддонов в машину, мешков и тонн в машине, занятый объём кузова |
| Партия | поддонов, мешков и тонн на заданное число машин |
| Час работ | время фасовки, время погрузки, итого последовательно и параллельно |
| Стоимость работ | фасовка, погрузка; итого и стоимость 1 т / 1 мешка |

## Ключевая логика

- **Объём груза на поддоне** = масса нетто / плотность / коэффициент
  заполнения. Коэффициент (0,7–0,8 для мешков) учитывает пустоты между мешками.
- **Поддонов в машину** = минимум из ограничения по массе и по объёму.
  В расчёте видно, какой лимит сработал: брикет — тяжёлый груз, поэтому обычно
  упирается в грузоподъёмность.
- **Высота пакета** = объём груза / площадь поддона + высота поддона (0,144 м).
  Если выше кузова — красное предупреждение.
- **Перегруз** — отдельное предупреждение, если поддоны тяжелее
  грузоподъёмности машины (например, при ручном переопределении).

## Параметры по умолчанию

Плотность брикета 1250 кг/м³ (Pini-Kay), мешок 30 кг, 33 мешка на европоддон
(990 кг, высота 1,24 м). Поддоны: EUR 1200×800 (0,96 м²), финский 1200×1000,
половинный 800×600. Машины: тент 20 т / 82 м³, тент 22 т / 92 м³, контейнеры
20' и 40', манипулятор, газель. Нормы: фасовка 60 мешков/час, погрузка вручную
40 мешков/час, тариф 250 грн/час — рыночная ставка Киева 2026.

**Значения ориентировочные.** Плотность брать у поставщика, нормы — по факту
смены. Обоснование норм и ставок — в `История_диалогов.md`.

## Возможности

- Тип поддона и тип машины переключаются на «Інший» — поля становятся
  редактируемыми для ручного ввода.
- Параметры сохраняются в localStorage браузера, кнопка «Скинути» возвращает
  значения по умолчанию.
- Кнопка «Друк / PDF» — печать текущего расчёта (форма ввода при печати
  скрывается, остаются только результаты).

## Ограничения

- Расчёт по одной позиции за раз, без накопительного списка партий.
- Раскладка поддонов по площади пола кузова не моделируется — для еврофуры
  это 33 поддона по факту против 32 в расчёте по массе.
- Погрузка в машину считается по той же норме, что переноска и укладка;
  отдельной нормы на подъём мешка в кузов нет.
- Нормы времени выведены расчётом из рыночных ставок, а не измерены
  хронометражем на конкретном производстве.
